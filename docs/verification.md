# 검증 기록

## 자동 검사

```bash
npm ci
npm run check
```

Node.js 내장 테스트 러너를 사용하므로 별도 테스트 서비스나 실제 API 키가 필요하지 않습니다. `tests/`는 산책 지수·예보 보간·요청 무효화와 실제 검색 composable의 상태를 검증합니다. GitHub Actions도 같은 명령을 실행합니다.

2026-11-04 로컬 결과: ESLint 통과, 기능 테스트 12개 통과, production build 성공.

자동 검사가 통과해도 외부 API의 가용성, 모든 브라우저의 GPS, 모든 시설의 개방 여부까지 보장하지 않습니다. 원본 이미지 및 Element Plus 번들 크기 경고는 남아 있습니다.
