현재 버전은 과제 6 기준으로 OpenWeather 실시간 날씨·대기질 API와
Kakao Local API의 행정동 변환과 공중화장실 장소 검색을 연동함.
.env의 두 API 키 값을 입력한 뒤 npm run dev를 재시작해야 함.
